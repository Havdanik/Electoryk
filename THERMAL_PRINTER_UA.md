# Термопринтер — v0.11

## Прямий Bluetooth Classic
Підтримані command languages:
- TSPL / TSPL2
- ZPL
- CPCL
- ESC/POS

З'єднання: RFCOMM SPP UUID `00001101-0000-1000-8000-00805F9B34FB`.

## Якщо принтер не друкує
1. Переконатися, що він **спарений** у Android Bluetooth.
2. Спробувати інший протокол.
3. Для BLE-only моделі використати `PNG-лист етикеток` через офіційний app принтера.
4. Для повної нативної інтеграції потрібна точна модель принтера/SDK.

## Чому direct label ASCII
Багато дешевих термопринтерів не мають Unicode/Cyrillic у вбудованих шрифтах. Тому direct TSPL/ZPL/CPCL/ESC-POS команда транслітерує текст, але код групи, кабель, CUT і автомат лишаються однозначними.

PNG fallback зберігає нормальний український текст.
