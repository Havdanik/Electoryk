## Що лишається для майбутнього окремого проходу
- live peer-to-peer синхронізація двох одночасно відкритих пристроїв;
- native BLE SDK для конкретної моделі термопринтера, якщо Bluetooth Classic протоколи не підійдуть;
- production telemetry / crash upload (зараз лог локальний);
- автоматичне резервне копіювання в хмару за бажанням;
- повноцінна база постачальників/онлайн-цін;
- PDF-рендер напряму з app без системного print dialog;
- багатокористувацькі ролі бригади з конфлікт-резолвом.
