# ElektorykScan v0.19.2 — Long Scan Stability

Цей прохід не додає новий тип сканера. Він стабілізує v0.19.1 для довгих реальних проходів кімнати.

## Що змінилось

- Зріла підтверджена стіна більше не розтягується від одного випадкового Depth-викиду.
- Новий край зрілої стіни додається поступово і лише після незалежного повторного підтвердження.
- Після невеликого ARCore/Depth дрейфу зріла площина повторно захоплюється канонічним Surface ID замість створення паралельного шару.
- Старі червоні одноразові tiles очищаються; жовта/зелена підтверджена пам'ять зберігається.
- Semantic entities дедуплікуються; слабкі одноразові помилки AI не накопичуються безкінечно.
- Зрілий semantic object має сильніший hysteresis типу: один випадковий кадр не перейменує його.
- У фінальну semantic-модель потрапляють лише підтверджені entities.
- Кнопка «стабільний скан ✓» з'являється лише якщо готовність і той самий wall-count тримаються 3 секунди поспіль.

## Regression

- 6+ проходів по одній шумній стіні -> 1 stable wall.
- Coplanar outlier не розтягує стіну.
- 18 см plane wobble після зрілого треку -> canonical reacquire, не дубль.
- Далекий одноразовий шматок не розширює зрілу стіну.
- Повторно підтверджений сусідній край може поступово розширити ту саму стіну.
- Semantic door, побачені кілька разів поруч, -> 1 committed entity.
