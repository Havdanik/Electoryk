# ElektorykScan v0.17.6 — Depth Tile Grid

Ця версія виправляє проблему v0.17.5, де ARCore Plane одразу зафарбовувався червоною сіткою по всій площині. Через це тимчасові/перекривні площини створювали «павутину» на шторах, меблях, стелі й дверях.

## Що змінилось

- Непросканована поверхня тепер **не малюється взагалі**.
- Клітинка сітки створюється лише тоді, коли реальний прийнятий Depth-семпл потрапив на конкретну ARCore Plane.
- Один Depth-кадр не може багаторазово підняти клітинку до жовтої/зеленої: рахується один незалежний кадр на клітинку.
- Червона клітинка = 1 незалежний Depth-кадр.
- Жовта = мінімум 2 незалежні Depth-кадри.
- Зелена = мінімум 3 кадри + бокове зміщення камери >= 18 см + кілька ракурсів.
- Кожна конструктивна площина отримує AR Anchor; сітка зберігається у координатах anchor, а не плаває за центром Plane.
- Підлога/стеля показуються тільки після фіксації архітектурного рівня; столи, ліжка та полиці не повинні автоматично ставати «підлогою».
- Візуалізація тепер складається з окремих 22-см клітинок; немає одного гігантського полігона з червоною текстурою.
- Клітинка не малюється, якщо її кути виходять за актуальний polygon площини.
- «Скан придатний» тепер вимагає також достатнього AR-grid покриття, а не тільки загальної статистики point cloud.
- Під час сканування UI став компактнішим: великий бренд-блок ховається, технічна RAW-діагностика не перекриває половину камери.

## Очікувана поведінка

1. Навести камеру на стіну — спочатку сітки може не бути.
2. Коли Depth реально підтвердив ділянку — з'являються локальні червоні клітинки тільки там, де є дані.
3. Пройти вздовж стіни / трохи зміститися боком — клітинки стають жовтими, потім зеленими.
4. Порожні ділянки лишаються без сітки.
5. Сітка не повинна заливати весь екран через одну велику ARCore Plane.
6. На ліжку/столі горизонтальна «підлога» не повинна з'являтися, якщо зафіксований рівень справжньої підлоги інший.
