# v0.17.8 — Depth Grid Fallback

Проблема v0.17.7: Depth-скан продовжував збирати геометрію, але AR-сітка могла залишатися 0%, якщо ARCore Plane не проходив жорсткий structural gate або Depth-точки не збігалися з Plane polygon.

Виправлення:
- сітка більше не залежить від наявності ARCore Plane;
- прийняті Depth-точки одразу заповнюють світову 10-см voxel-сітку;
- red/yellow/green вимагають незалежних кадрів, а green також baseline >= 18 см і >=2 ракурси;
- provisional tiles мають фіксовані world centers, тому не рухаються разом з екраном;
- коли надійна ARCore Plane-сітка доступна, вона має пріоритет;
- UI прямо показує Depth-сітка або AR-сітка;
- завершення скану більше не блокується тільки через слабке Plane tracking, якщо Depth-сітка достатньо підтверджена.
