# ElektorykScan v0.20.0 — 3D Workspace Editor

## Що змінилось

3D більше не є окремою демонстрацією. Він працює як редактор єдиної моделі квартири.

### Камера
- **Orbit** — обертання одним пальцем; pinch zoom; двома пальцями pan.
- **Walk** — огляд із рівня людини всередині кімнати.
- **Top** — швидкий контроль планування зверху.
- **Cutaway** — ховається стіна, що реально перетинає промінь камера → центр сцени.

### Вигляд
- PHOTO — скановані UV-текстури там, де вони надійні.
- SOLID — чисті суцільні матеріали.
- WIRE — каркас для перевірки геометрії.
- Окремі перемикачі стелі, 0.5-м сітки, меблів і електроточок.

### Selection + Inspector
- Стіна: товщина, конструктивний матеріал, finish, товщина finish.
- Двері/вікно/прохід: тип, ширина, висота, низ від підлоги.
- Меблі: W/D/H, rotation, nudge 5 см, drag, delete.
- Електроточка: модулі, кабель, висота, offset по стіні, навантаження, група.

### Історія
Undo/Redo тримає до 30 snapshot-ів і відновлює одночасно `ApartmentPlan` та `FloorPlan`, щоб 3D і 2D не роз'їжджалися.

### Безпека геометрії
3D-інспектор не дозволяє випадково тягнути вершини конструктивних стін. Для зміни контуру лишається окремий 2D Geometry Editor. Це навмисно: finish/objects/openings можна правити в 3D, а топологію стін — у точному 2D режимі.
